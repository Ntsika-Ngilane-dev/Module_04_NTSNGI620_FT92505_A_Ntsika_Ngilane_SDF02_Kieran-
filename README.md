
# 🐾 CodeSpace Cat’s Portfolio

This is a fun and professional HTML/CSS portfolio project themed around CodeSpace Cat — a web-loving feline! Below is an overview of the project structure and functionality.

---

## 📄 File Overview

**`index.html`** — The main HTML file that includes all the sections of the portfolio.
**`images folder`** — This where all the images for the project are.
---

## 🔧 Structure Documentation

### 1. <!DOCTYPE & HTML Declaration
```html
<!DOCTYPE html>
<html lang="en">
```
- Declares HTML5 document type.
- Sets the language to English.

---

### 2. <head> Section
```html
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>CodeSpace Cat's Portfolio</title>
```
- Character encoding: UTF-8.
- Viewport: Enables responsiveness.
- Title: Sets the browser tab title.

---

### 3. Internal CSS Styles
```html
<style>
  /* Typography and layout */
  body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
  }

  h1, h2, h3 {
    color: #333;
  }

  nav ul {
    padding: 0;
  }

  nav ul li {
    margin-right: 15px;
  }

  table {
    width: 100%;
    border-spacing: 20px;
  }

  td img {
    width: 300px;
    height: auto;
    display: block;
  }

  form input, form textarea {
    margin: 5px;
  }
</style>
```

---

### 4. <body> Sections

#### Header
Contains the main title and navigation links.

#### About Me
Includes a cat image and intro paragraph with puns and personality.

#### Skills
An unordered list of both technical and whimsical skills.

#### Portfolio
Displays a table of sample projects with thumbnails and descriptions.

#### Contact
Form with fields for name, email, and message.

#### Footer
Basic copyright.
